## Global Constraints
- Phase 1 제약 전부 유지 (Phaser 3.80.1 CDN, 540×960, 위치 기반 이동, 대상별 히트스톱, 일시정지 중 피격 없음, 수치는 JSON, `src/systems/`는 Phaser/window 미참조).
- 저장 키 `manaSeedDefense.save.v1` 유지, 기본값 병합으로 기존 저장과 호환.
- 커밋 형식 `Add:`/`Fix:` + Co-Authored-By.
- 매 태스크 끝: `cd prototype && npm test` 통과 + (화면 태스크) 브라우저 스모크(콘솔 에러 0, 해당 기능 JS로 확인).

## Tasks

### 2-A 몬스터 & 특수 웨이브
- **A1 데이터**: `monsters.json`에 `behavior` 필드 + swarm/ranged/dasher/splitter/splitling/bard/sera/leprechaun. `story.json`(정예·보스 이름/칭호/회차별 등장·처치 대사/사연 조각 3개, 인트로 3장). `waves.json` 1~15. 테스트: 모든 웨이브 id 존재, 정예·보스 대사 3회차분, behavior 값이 허용 목록.
- **A2 WaveGen + WaveRun 확장** (`systems/WaveGen.js`, `WaveSystem.js`): `generateWave(wave, balance, rng) → [{id,count}]`(16+), `waveComposition`이 16+에서 WaveGen 사용, `WaveRun.addExtra(n)`, `WaveRun.specials → {elites:[], boss}`. 테스트: 5의 배수 보스·3의 배수 정예·겹치면 보스, 총량=공식, addExtra 후 클리어 조건.
- **A3 Combat/Story 순수 계산** (`systems/Combat.js`, `systems/Story.js`): `captainShare(dmg, inAura)`, `bardAtkMul(escorts)`, `seraSpeedMul(rage)`, `bossInterval(hpRatio)`, `stealRank(ranks, rng) → {ranks, stolenId}`, `returnStolen(ranks, stolen)`, `lineFor(storyEntry, kind, encounter)`, `unlockedFragments(entry, kills, isBoss)`. 테스트 각 1~3개.
- **A4 Monsters.js 분리**: GameScene의 몬스터 스폰·이동·코어타격·사망을 `game/Monsters.js`로 이동 + 약한 분리(separation). 동작 동일 (스모크: 웨이브 1 클리어).
- **A5 일반 행동 + 탄환**: swarm(덩어리 스폰), ranged(정지·조준선·탄환), dasher(경고선·돌진·정지), splitter(분열). `game/Projectiles.js`.
- **A6 정예·보스 + 연출**: bard(부하·헌신·결속·흩어짐·공성), sera(플레이어만·돌진·멍함·분노), leprechaun(3패턴·강탈/반환·공성). `ui/Banner.js`(예고 배너, 대사창, 붉은 테두리), 머리 위 체력바, 파란/금 마나시드. 회차 카운트 저장.

### 2-C 대시·스킬
- **C1**: `game/Player.js` 분리(이동·피격·공격) + 대시 + 워든 스킬 + 우하단 버튼 2개(쿨 표시) + Space/Q.

### 2-B 로비·상점
- **B1 순수**: `systems/Save.js`(기본값 병합·기록 함수), `systems/Shop.js`(`priceOf`, `canBuy`, `buy`, `runModifiers(save, shop) → {hpMul, atkMul, moveMul, coreHpMul, coreRegenAdd, harvestMul, freeCard, extraCards:[], ...}`). 테스트.
- **B2 화면**: `LobbyScene`, `ShopScene`, `IntroScene`, 결과화면 버튼 변경, 런 시작 시 상점 효과 적용(시작 스탯·코어·환수율·첫 선물·새 카드 풀).

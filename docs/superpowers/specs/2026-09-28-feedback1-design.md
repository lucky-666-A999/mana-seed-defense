# 피드백 1차 반영 설계 (Phase 2.5)

> 작성일: 2026-09-28 · 상위: `2026-09-28-phase2-3-design.md`
> Lucky 피드백: ① 가운데 가만히 서 있어도 클리어됨 ② 준비 시간에 할 게 없음 ③ 초반에 스킬을 맛보게 ④ 전직을 먼저 유도하고, 전직 후 성장 트리에서 스킬을 본격 성장
> 확정: ①은 "가운데 = 안전하지만 가난, 밖 = 위험하지만 부유", 4웨이브부터 적용. ②는 정비소(이번 판 경험치 소비).

## 흐름 한눈에
```
로비 (첫 목표: "5웨이브 이상에서 마무리 → 전직 해금")
 → 출전: 마나 스킬 3개 중 1개 골라 시작 (스킬 맛보기)
 → 1~3웨이브: 지금처럼 가운데서도 됨 (튜토리얼)
 → 4웨이브~: 외곽 마나 결정(보상) + 포격 프로그램(코어 원거리 공격) → 나가야 함
 → 준비 단계: 정비소에서 경험치를 코어·카드·스킬에 투자 (쓸수록 환수액↓)
 → 마무리 → 전직 해금 → 성장 탭에 [전직] 트리 열림 → 전직 전용 성장
```

## 1. 코어 캠핑 대책 (4웨이브부터)

### 1-1. 포격 프로그램 (채찍)
- id `artillery`, 이름 「포격 프로그램」. 코어에서 **340px**(모든 직업 사거리 밖)에 멈춰 3초마다 코어에 포탄.
- 포탄: 코어 위에 0.9초 착탄 원 예고 → 코어 10 피해. 플레이어가 착탄 원 안이면 플레이어도 12 피해.
- 체력 30, 속도 40, 경험치 4. 가만히 있으면 코어가 확실히 깎이고, 잡으려면 나가야 한다.
- 등장: 웨이브 4·6·9·12·14 등 편성, 자동 편성(16+) 비율 10%.

### 1-2. 마나 결정 (당근)
- 4웨이브부터 전투 시작 시 외곽(코어에서 430~600px)에 결정 **2개** 생성.
- 결정 반경 44 안에 서 있으면 **3초간 채집 게이지** 충전(밖에 나가면 천천히 줄어듦). 가득 차면 터지며 파란 마나시드로 보너스 경험치 `4 + 웨이브×1.5`.
- 웨이브가 끝나면 남은 결정은 사라짐 → "지금 나갈까" 결정이 매 웨이브 생긴다.

## 2. 정비소 (준비 단계)
- 준비 단계 HUD에 **[정비]** 버튼. 누르면 정비 패널(게임 일시정지).
- 화폐 = **환수 가능 경험치** = 이번 판 누적 경험치 − 정비에 쓴 양. 레벨·경험치 게이지엔 영향 없음. 마무리 시 이 값이 환수됨.
- 항목 (가격은 웨이브에 비례):
| 항목 | 효과 | 가격 | 제한 |
|------|------|------|------|
| 코어 수리 | 코어 최대 체력의 30% 회복 | 8 + 웨이브×2 | 준비당 2회 |
| 전투 보급 | 카드 3장 중 1장 선택 | 12 + 웨이브×3 | 준비당 1회 |
| 스킬 연마 | 직업 스킬 쿨다운 −10% (이번 판) | 20 + 웨이브×2 | 판당 3회 |
| 결계 발전기 | 다음 웨이브 동안 코어 받는 피해 −30% | 10 + 웨이브×2 | 준비당 1회 |
- 패널에 "지금 마무리하면 환수: N" 항상 표시.

## 3. 스킬 맛보기 — 마나 스킬
직업과 무관한 자동 발동 스킬 4종 (후더덕의 운석·냉기 보호막·집중 레이저 참고). 출전하면 **무작위 3개 중 1개**를 골라 시작하고, 레벨업 카드로 새로 얻거나 레벨(최대 5)을 올린다.

| id | 이름 | 동작 (Lv1 → Lv5) |
|----|------|------|
| meteor | 운석 | 주기마다 가까운 적 위치에 0.5초 예고 원 → 낙하. 주기 4s→2.4s, 반경 70→110, 공격력 1.8→3.0배 |
| frost | 냉기 보호막 | 플레이어 주변 원(92→140) 안의 적 감속 35→55%, 0.6초마다 공격력 0.3→0.5배 |
| laser | 집중 레이저 | 주기마다 0.25초 충전선 → 가장 가까운 적 방향 320px 관통 광선. 주기 3.5s→2.3s, 1.4→2.6배 |
| orbit | 씨앗 궤도 | 플레이어 주위를 도는 씨앗 2→6개, 닿으면 0.7→1.1배 (같은 적 0.5초 간격) |

- 카드풀에 마나 스킬 카드 4장 추가(일반 등급, 최대 5단계). 가진 스킬은 레벨업, 없는 스킬은 새로 획득.

## 4. 전직 먼저 → 전직 성장 트리
- 전직 해금 조건 완화: 그 직업으로 **5웨이브 이상에서 마무리** + 마나시드 **60** (기존 10웨이브·150).
- 로비에 **다음 목표** 한 줄 안내: 전직 전 → "첫 목표: 5웨이브 이상에서 마무리하면 전직 해금", 전직 후 → "[광전사] 성장 트리가 열렸다".
- 성장(상점)에 **[전직] 탭**: 현재 선택한 직업·전직의 전용 노드 3개(각 3단계, 가격 40/90/160).

| 전직 | 노드 1 | 노드 2 | 노드 3 |
|------|--------|--------|--------|
| 광전사 | 피의 갈망: 처치 시 체력 +1 | 광기: 광전 공격력 +15% | 폭주: 공격속도 +8% |
| 수호자 | 성벽: 코어 최대 체력 +10% | 결계 연장: 코어 무적 +1초 | 가시 성벽: 코어 반사 +10 |
| 검성 | 정밀: 치명 +5% | 필살: 치명 피해 +0.3배 | 속검: 공격속도 +8% |
| 그림자 | 잔영: 대시 쿨 −10% | 그림자 칼날: 대시 피해 +0.5배 | 질주: 이동속도 +6% |
| 저격수 | 원거리: 사거리 +10% | 사냥 표식: 정예·보스 피해 +15% | 강궁: 공격력 +8% |
| 사냥꾼 | 연사: 화살 +1 (2단계) | 추격: 처치 가속 +10% | 관통: 관통 +1 |
| 대마법사 | 확장: 폭발 반경 +10% | 집중: 공격 간격 −5% | 마력: 공격력 +8% |
| 원소술사 | 불씨: 화상 +10% | 번짐: 폭발 반경 +8% | 연쇄: 연쇄 폭발 (1단계) |

## 5. 기술
- 순수 로직(테스트): `systems/Workshop.js`(정비 가격·제한·환수 가능액), `systems/ManaSkills.js`(레벨별 수치), 상점 `kind: 'specNode'` 처리, 전직 조건 데이터화(balance.specUnlock).
- 게임: `game/Crystals.js`(결정 생성·채집), `game/ManaSkills.js`(자동 스킬 실행), Monsters에 `artillery` 행동·감속(slow) 지원, `ui/Workshop` 패널, 출전 시 마나 스킬 선택 오버레이.
- 검증: 생존 봇에 **코어 위에만 서 있는 캠핑 봇**을 추가해 4웨이브 이후 코어가 깎여 무너지는지 확인. 보통 봇(결정 채집 포함)과 비교.

## 1. 한 줄 컨셉

**"마나시드 코어를 지키며 끝없는 웨이브를 막는 탑뷰 액션 디펜스. 웨이브마다 '더 갈까, 여기서 챙길까'를 고르는 하이리스크 로그라이트."**

핵심 재미 3축:
1. **타격감** — 직접 움직이며 때리는 손맛
2. **빌드** — 레벨업마다 직업별 3택 카드로 매 판 다른 성장
3. **결단** — 계속할수록 보상↑, 죽으면 전부 잃음. 그만두는 타이밍이 실력

---

## 2. 세계관 연결 (마나시드 RTS 계승)

- 주인공은 시뮬레이션의 **"버그"** — 관리자가 의도하지 않은 의식.
- 2045년 초지능 AI가 과거로 보낸 **마나시드**가 주인공 손에 도착.
- 이 게임의 **거점 = 땅에 심은 마나시드 코어**. 코어가 자라야 탑으로 가는 길이 열린다.
- 몬스터 = 시뮬레이션 관리자가 보낸 **"수정 프로그램"**. 버그(주인공)와 마나시드를 지우러 사방에서 몰려온다.
- "마무리"로 회수한 경험치가 **결정화된 마나시드**가 되어 다음 판의 주인공을 강하게 만든다 = "버그가 스스로를 업데이트한다."

> 스토리 연출은 Phase 1 범위 밖. 텍스트 인트로 1장 정도만 둔다.

## 3. 핵심 루프

### 3-1. 런(1판) 루프
```
런 시작 (Lv1, 거점 풀체력)
  → [준비 단계] 기본 60초 — 몬스터 없음, 이동/포지셔닝만
  → [전투 단계] 지정 몬스터 스폰 → 전부 처리되면 웨이브 클리어
  → [선택 팝업] 이어가기 / 마무리
       ├─ 이어가기 → 다음 웨이브 준비 단계로
       └─ 마무리  → 누적 경험치 전액 → 마나시드(영구자산) 환수 → 결과화면
  (언제든) 플레이어 사망 또는 거점 파괴 → 누적 경험치 전부 소멸 → 결과화면
```

### 3-2. 전투 마이크로 루프 (3~5초 안에 완결)
```
조이스틱 이동 → 자동공격으로 몬스터 처치 → 마나시드 드롭 → 자석 흡수
  → 경험치 게이지↑ → 가득 차면 즉시 일시정지 + 3택 카드
```

## 4. 웨이브 & 거점 방어

### 4-1. 맵 구조 — 방사형 방어
- 맵 중앙에 **마나시드 코어(거점)** 1개. 체력 보유.
- 몬스터는 맵 가장자리 스폰 지점에서 **코어를 향해 직진**. 플레이어가 막지 않으면 코어 도달.
- 플레이어는 코어 주변을 자유 이동하며 요격.
- 맵 크기: 화면 약 1.5배 (카메라가 플레이어 추적). 코어가 화면 밖이면 방향 화살표 표시.

### 4-2. 스폰 방향 확대 (포위 압박)
| 웨이브 | 스폰 방향 수 |
|--------|-------------|
| 1~2 | 2방향 |
| 3~5 | 4방향 |
| 6~9 | 6방향 |
| 10+ | 8방향 (전방위) |

### 4-3. 웨이브 클리어 규칙 (확정)
- 각 웨이브는 `waves.json`에 **처리해야 할 몬스터 목록**을 가진다. 예: `돌격형 x15 + 정예 x2`.
- 몬스터는 두 가지 방법으로 "처리됨" 처리:
  1. 플레이어가 처치 → 경험치 드롭
  2. 코어에 도달 → **코어에 대미지를 주고 소멸** (경험치 없음)
- 목록 전부 처리되면 웨이브 클리어. (코어 도달도 처리로 치므로 웨이브가 영원히 안 끝나는 일 없음)
- 전투 단계에는 **제한시간 없음**.
- 클리어 순간 바닥에 남은 마나시드는 **자동 흡수**한 뒤 팝업을 띄운다 (마무리 환수 금액에 포함되도록).

### 4-4. 준비 단계
- 기본 **60초**. `waves.json`의 `prepSeconds` 값 하나로 전 웨이브 공통 조정. 웨이브별 덮어쓰기 허용.
- 준비 중: 몬스터 없음, 이동만 가능. 화면 상단 카운트다운.
- **"바로 시작" 버튼**으로 남은 준비시간 건너뛰기 가능.

### 4-5. 웨이브 사이 회복 (튜닝값)
| 대상 | 규칙 | 기본값 |
|------|------|--------|
| 플레이어 체력 | 준비 단계 진입 시 회복 | 100% |
| 코어 체력 | 웨이브 클리어 시 회복 | 최대치의 20% |

→ 코어는 거의 회복되지 않으므로 "코어 체력이 얼마 남았나"가 이어가기/마무리 판단의 핵심 근거가 된다.

### 4-6. 웨이브 유형 3종 (후더덕 참고)
| 유형 | 등장 | 구성 | 예고 연출 |
|------|------|------|----------|
| 일반 | 기본 | 잡몹 지정 수량 | 없음 |
| 정예 | 3의 배수 웨이브 | 잡몹 + 정예 1~2 | 준비 단계에 "정예 접근" 경고 + 사운드 |
| 보스 | 5의 배수 웨이브 | 잡몹 + 보스 1 | 화면 붉은 테두리 + 강한 경고음 |

(3과 5의 공배수인 15웨이브 등은 보스 우선)

### 4-7. 무한 웨이브 생성
- 1~10웨이브: `waves.json`에 수동 정의 (튜토리얼 곡선).
- 11웨이브~: **공식으로 자동 생성**. 마지막 정의 웨이브를 기준으로 수량·스탯 스케일.

### 4-8. 난이도 스케일 (ManaTower 수식, 층 F → 웨이브 W)
```
몬스터 체력   = base_hp  × (1 + 0.18 × (W-1))
몬스터 공격   = base_atk × (1 + 0.12 × (W-1))
웨이브 몬스터 수 = 5 + floor(W × 1.5)
스폰 간격     = max(0.4s, 2.0s - 0.1 × W)
```
계수는 전부 `balance.json`. 플레이어 성장이 곡선을 **약간 앞서도록** 튜닝하고, 정예/보스 웨이브로 주기적 스파이크.

## 5. 런 내 성장 — 경험치 & 3택 카드

### 5-1. 마나시드 드롭 (ManaTower 계승)
| 색 | 등급 | 경험치 | 출처 |
|----|------|-------|------|
| 흰녹 | 하급 | 1 | 잡몹 |
| 청 | 중급 | 5 | 정예 |
| 보라 | 상급 | 20 | 미니보스 (Phase 3 예약, Phase 1~2 미사용) |
| 금 | 최상급 | 100 | 보스 |

플레이어 근처로 오면 자석 흡수. 드롭은 15초 후 소멸.

### 5-2. 레벨업
- 경험치 게이지가 차면 **즉시 일시정지 + 카드 3장** 제시, 1장 선택.
- 한 번에 여러 레벨업 → 큐에 넣고 한 장씩 순서대로.
- 필요 경험치: `need(L) = 10 + 6 × (L-1)` (`balance.json`).

### 5-3. 카드 풀 & 등급 상한 (확정)
카드 = **직업 전용 스킬** + **공통 스탯 강화**. 각 카드는 등급을 가진다.

**① 등급 해금 (플레이어 레벨 기준)**
| 등급 | 등장 가능 레벨 | 기본 등장 가중치 |
|------|---------------|-----------------|
| 일반 | Lv1+ | 60 |
| 희귀 | Lv5+ | 25 |
| 영웅 | Lv10+ | 12 |
| 전설 | Lv15+ | 3 |

해금 전 등급은 가중치 0. 해금 후 레벨이 오를수록 상위 등급 가중치 소폭 상승 (`balance.json`).

**② 카드별 최대 강화 단계 (등급 기준)**
| 등급 | 최대 단계 |
|------|----------|
| 일반 | 5 |
| 희귀 | 4 |
| 영웅 | 3 |
| 전설 | 1 |

최대 단계에 도달한 카드는 풀에서 제외. 뽑을 카드가 3장 미만이면 "체력 회복 / 마나시드 보너스" 같은 대체 카드로 채운다.

**③ 3장 뽑기 규칙**
- 같은 카드 중복 제시 금지.
- 현재 직업 전용 카드 + 공통 카드 풀에서 가중치 추첨.

### 5-4. 카드 예시 (워든, Phase 1용)
| 카드 | 등급 | 효과 |
|------|------|------|
| 공격력 강화 | 일반 | 공격력 +15% |
| 공격 속도 | 일반 | 공격속도 +10% |
| 이동 속도 | 일반 | 이동속도 +8% |
| 흡수 반경 | 일반 | 마나시드 흡수 반경 +20% |
| 최대 체력 | 일반 | 최대 체력 +20% |
| 넓은 휘두르기 | 희귀 | 부채꼴 각도 +20° |
| 충격파 | 희귀 | 3타마다 주변 넉백 파동 |
| 코어 수호 | 영웅 | 코어 근처에서 받는 피해 -30% |
| 대지 강타 | 전설 | 10초마다 화면 전체 몬스터 기절 1초 |

## 6. 런 종료 & 영구 성장

### 6-1. 종료 규칙 (확정)
| 종료 방식 | 경험치 처리 |
|----------|-------------|
| **마무리** (웨이브 클리어 후 선택) | 이번 판 **누적 획득 경험치 100%** → 마나시드 |
| **사망** (플레이어 체력 0) | 전부 소멸 |
| **거점 파괴** (코어 체력 0) | 전부 소멸 |

- "누적 획득 경험치" = 이번 판에서 주운 경험치 총합 (레벨업에 쓴 것 포함).
- 환율 기본 1:1 (`balance.json`의 `expToSeed`).
- 마무리는 **웨이브 클리어 직후 팝업에서만** 가능. 전투 중 도망 불가.

### 6-2. 영구 성장 상점 (ManaTower "결정화 마나시드" 계승)
| 항목 | 내용 |
|------|------|
| 직업 해금 | 검사 → 궁수 → 술사 순차 해금 |
| 전직 | 조건(예: 워든으로 10웨이브 마무리) 달성 후 상위 직업 분기 (광전사/수호자 등) |
| 시작 스탯 | 최대 체력 +, 공격력 +, 이동속도 + (단계별 비용 증가) |
| 코어 강화 | 코어 최대 체력 + |
| 카드 풀 확장 | 새 카드 해금 → 런 내 3택에 등장 |

- 저장: 브라우저 `localStorage` (프로토타입). 키 1개에 JSON.

## 9. 기술 설계

### 9-1. 스택
- **Phaser 3** (브라우저 실행, 빌드 도구 없음 — CDN 스크립트 + ES 모듈).
- 저장: `localStorage`.

### 9-2. 폴더 구조
```
ManaSeedDefense/
  docs/                       설계 문서
  prototype/
    index.html
    src/
      main.js                 Phaser 설정, 씬 등록
      scenes/
        BootScene.js          데이터 로드
        GameScene.js          전투 (플레이어/몬스터/코어/드롭)
        UIScene.js            HUD, 카드, 팝업 (GameScene 위에 겹침)
        ShopScene.js          영구 성장 상점 (Phase 2)
      systems/
        WaveSystem.js         준비/전투 상태, 스폰, 클리어 판정, 무한 생성
        CardSystem.js         등급 해금·가중치·최대단계·3장 추첨
        Progression.js        경험치/레벨, 환수, localStorage 저장
      entities/
        Player.js  Monster.js  Core.js
    data/
      classes.json            직업
      monsters.json           몬스터 스탯
      waves.json              웨이브 1~10 + prepSeconds
      cards.json              카드 풀 (등급, 최대단계, 효과)
      balance.json            스케일 계수, 레벨 곡선, 회복률, 환율, 등급 가중치
```
각 system은 Phaser에 의존하지 않는 순수 로직으로 작성 → 브라우저 없이 Node로 단위 검증 가능.

### 9-3. 데이터 주도 원칙
하드코딩 금지 수치: 준비시간, 스폰 방향 수, 난이도 계수, 레벨 곡선, 등급 해금 레벨·가중치·최대단계, 회복률, 환율. 전부 JSON.

### 9-4. ManaTower에서 배운 기술 교훈
- 이동은 **위치 기반 수동 적분** (`x += vx * dt`). Arcade 바디 velocity는 수동 스텝 검증에서 안 움직임.
- 충돌은 거리 기반 판정.
- 히트스톱은 전역 `time.timeScale` 쓰지 말 것 (전체 게임 멈춤 버그).
- 헤드리스 검증용으로 `window.__game` 노출, `step(t, 16)`으로 수동 구동.
- 일시정지(카드/팝업) 중에는 피격 판정 차단 (카드 보는 중 사망 방지).
- JSON 로드 시 캐시 버스팅 쿼리.

### 9-5. 검증
- `WaveSystem`, `CardSystem`, `Progression`: Node로 돌리는 `assert` 기반 자가검증 스크립트 1개씩.
  - 웨이브: 목록 전부 처리 시 클리어 / 코어 도달도 처리로 카운트 / 11웨이브 자동 생성.
  - 카드: Lv4에서 희귀 미등장 / 최대단계 카드 제외 / 3장 중복 없음.
  - 환수: 마무리 = 누적경험치×환율 / 사망 = 0.
- 브라우저: 프리뷰로 이동·웨이브 클리어·레벨업·마무리 흐름 확인.

## 10. 로드맵

### Phase 1 — MVP (재미 검증) ← 첫 구현 범위
- 조이스틱(+키보드) 이동
- 워든 자동공격 + 타격감 필수 3종
- 중앙 코어 + 돌격형 1종, 방사형 스폰
- 웨이브 1~10 + 11웨이브부터 자동 생성, 준비 60초 + 바로시작
- 경험치 게이지 + 3택 카드 (워든 카드 9종, 등급 상한 포함)
- 웨이브 클리어 팝업: 이어가기/마무리
- 결과 화면 + 누적 마나시드 저장 (상점 UI는 없음, 숫자만 표시)

### Phase 2 — 코어 확장
- 몬스터 4종 추가, 정예/보스 웨이브 + 예고 연출
- 영구 성장 상점 (시작 스탯, 코어 강화, 카드풀 확장)
- 직업 스킬 버튼, 회피 대시

### Phase 3 — 메타
- 검사/궁수/술사 해금, 전직 트리
- 스토리 연출 (마나시드 RTS 세계관)
- 밸런스 심화 (휴먼 플레이테스트 기반)

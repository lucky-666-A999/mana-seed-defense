# 아이템과 숨겨진 전직 · 판 안 거점 설계

> 작성일: 2026-09-28 · Lucky 승인 완료
> Lucky 지시: "레벨업 선택 카드에 아이템도 섞는다. 시작·모션은 똑같고, 활·지팡이 같은 조합을 얻으면 전직하는 숨겨진 전직 조건 해금 트리" + "스테이지 진행 중 마나시드를 얻어 아이템 강화소·가챠샵·스킬트리 정비를 할 수 있는 곳"
> 대체하는 것: 로비 직업 선택, 상점 직업 구매, 전직 구매(5웨이브 마무리 조건).

## 1. 화폐
| 이름 | 어디서 | 쓰임 |
|------|--------|------|
| **마나시드** | 판 안에서 줍는 것 (= 경험치) | 레벨업 + 거점(정비·가챠·강화·스킬 정비). 쓴 만큼 환수액 감소 |
| **결정화 마나시드** | 마무리 시 남은 마나시드가 결정화 (사망·코어 파괴 시 0) | 로비 성장 트리 (능력·카드 해금·전직 노드) |

## 2. 판 안 전직 (2단)
- 모두 **몽둥이 워든**으로 시작.
- 레벨업 3택 중 한 장이 **아이템 카드**로 바뀔 확률 40% (지금 단계에서 얻을 수 있는 아이템이 남아 있을 때).
- 아이템은 판마다 종류별로 1개씩(중복 없음), 각자 작은 효과가 있다. 가진 아이템의 **짝**이 나올 확률 ×3.
- 조합이 갖춰지는 순간 게임이 멈추고 **전직 연출** → 공격 모션·스킬·오라가 그 자리에서 바뀜.

| 단계 | 조건 | 결과 |
|------|------|------|
| 1차 | 워든 + 검 + 숫돌 | 검사 |
| 1차 | 워든 + 활 + 화살통 | 궁수 |
| 1차 | 워든 + 지팡이 + 마나석 | 술사 |
| 2차 | 워든 + 핏빛 두건 + 전투 북 | 광전사 |
| 2차 | 워든 + 방패 + 코어 파편 | 수호자 |
| 2차 | 검사 + 명검 조각 + 수련서 | 검성 |
| 2차 | 검사 + 그림자 망토 + 단검 | 그림자 |
| 2차 | 궁수 + 조준경 + 황금 화살 | 저격수 |
| 2차 | 궁수 + 사냥 나팔 + 덫 | 사냥꾼 |
| 2차 | 술사 + 고대 마도서 + 수정구 | 대마법사 |
| 2차 | 술사 + 불꽃 정수 + 화산석 | 원소술사 |

- 나오는 아이템 풀은 **지금 위치에서 갈 수 있는 조합의 재료만**: 워든이면 1차 재료 6 + 워든 2차 재료 4, 궁수면 궁수 2차 재료 4, 2차 전직 후엔 없음.
- 전직의 시각 차별화: 오라 색, 공격 변화(회전 베기·충전 화살·메아리 폭발 등), 스킬 강화 (`specs.json`의 color·attackMod·skillMod).

## 3. 숨겨진 조합과 발견
- 처음엔 모든 조합이 `???` + 힌트 한 줄 (기록 > 전직 도감).
- 판 안에서 전직하면 그 조합이 **영구 발견**: 도감에 공개, 로비 성장 트리 [전직] 탭에 그 전직의 전용 노드가 열림.

## 4. 판 안 거점 (준비 단계)
준비 단계 HUD의 **[거점]** 버튼 → 탭 4개. 전부 이번 판 마나시드로 결제.
- **정비**: 코어 수리·전투 보급·스킬 연마·결계 (기존)
- **가챠**: 지금 풀에서 아이템 1개 뽑기. 가격 `15 + 웨이브×3`, 준비당 2회. 뽑은 아이템도 조합 판정.
- **강화소**: 가진 아이템 강화 +1~+3 (효과 ×1.5 / ×2 / ×2.5). 가격 `12/24/40 + 웨이브×2`.
- **스킬 정비**: 가진 카드 1단계 올리기(가격 `10 + 현재단계×6 + 웨이브`), 1단계 되돌리기(그 단계 가격의 50% 환불).

## 5. 로비·영구 성장
- 로비: 직업 선택 제거. "숨겨진 전직 발견 N/11" 표시.
- 성장: 능력 / 해금(카드) / 전직(발견한 전직의 노드) 탭. 직업·전직 구매 항목 제거.
- 결과·로비의 영구 재화 표기를 "결정화 마나시드"로.

## 6. 기술
- 데이터: `items.json`, `recipes.json`, `balance.items`(확률·짝 배율·가챠·강화 가격)
- 순수 로직: `systems/Items.js` (풀·가중치·조합 판정·아이템 스탯·강화·가챠·스킬 정비 가격) — 테스트
- 게임: 레벨업 손패에 아이템 섞기, `transform()`, 전직 연출, 거점 탭 UI, 전직 오라·공격 변화
- 저장: `discovered: {recipeId: true}`

## 7. 구현 메모 (2026-09-28)
- 레벨업 손패의 마지막 칸이 40% 확률로 아이템 카드(주황 테두리·"아이템" 표시, "조합 재료?" 문구).
- 전직 연출 중 전직 순간 화면 번쩍임 + 직업 스킬 쿨다운 즉시 초기화(전직 보상).
- 2차 전직의 코어 체력 보정(수호자)은 전직 순간 코어 최대 체력을 늘리고 차이만큼 회복.
- 전직별 공격 변화는 `specs.json`의 `attackMod`(wideRed·guardWave·comboFinisher·blinkStrike·chargedShot·ricochet·echoBlast·fireGround)와 `skillMod`.
- 거점 탭 UI는 `ui/Overlays.js showHub`, 로직은 `GameScene.hubContext`와 핸들러.
- 삭제: 로비 직업 선택·전직 구매(`Specs.js`는 노드 합산만 남김), 상점 직업 구매.

## 8. 5차 전직과 강화 도박 (2026-09-28 추가, Lucky 승인)
- 3·4·5차 = 2차 전직 재료 두 개의 낮은 쪽 강화 단계 +2 / +3 / +4. 강화 단계가 떨어져도 오른 차수는 유지.
- 강화 +1~+5: 성공률 95/85/70/55/40%, 대성공 8%(두 단계), +4 이상 도전 실패 시 50% 확률로 한 단계 하락. 가격 12/24/40/60/90 + 웨이브×2.
- 차수 보너스: 공격력 +10%·공속 +5% (차수마다), 전직 고유 기술 배율 +25%/차, 4차 사냥꾼 두 번 튕김, 5차 각성 파동(3타마다 전직 색 파동). 오라·무기 광채가 차수마다 커짐.
- 강화 연출: 1.1초 긴장(흔들림·빛 모으기·불꽃 수렴) → 성공(금빛 고리·폭발) / 대성공(무지개) / 실패(균열·회색 연기) / 하락(붉은 문구).
- 기록 도감: 2차 행에 3~5차 발견 ★ 표시.

## 9. 보류: 로비·성장 문구 정리 (Lucky: "문구는 차차")
- 전직 도감 카운트를 1차/2차/상위(36) 기준으로
- "강화"는 아이템 강화에만, 전직 연구는 "연구·영구 보너스"로 통일
- 로비에 "마무리해야 결정화 · 성장에서 사용" 규칙 한 줄
- 진행도별 안내 문구 (발견 0 / 1차만 / 2차 이후)

## 10. 스킬 수련 경로 (2026-09-28, Lucky 제안)
- 아이템은 확률 의존적이라 **확실한 경로**를 추가: 초보자 전용 카드 [막대 수련](최대 3, 가중치 ×2).
- 수련 1단계마다 막대 내려치기 범위 +15, 위력 +0.5배. Lv3 → **수련의 갈림길**: 검의 길(검사) / 활의 길(궁수) 선택 → 즉시 1차 전직.
- 거점 스킬 정비(+1)로 마나시드를 써서 확실히 올릴 수 있다. 워든·술사와 2차 이후는 아이템·강화 경로만.
- 도감: 검사·궁수 행에 "또는 막대 수련 Lv3 → 검/활의 길" 표시. 전직 연출은 "경로: 막대 수련 Lv3".

# 스타일 가이드 — 1차 초벌 (2026-09-29)

Lucky: "완전 구현 아니고 뼈대 정도로, 느낌만 볼 수 있게." 방향 확정 전 임시안이다.

## 방향: 어두운 보랏빛 땅 위에서 마나가 빛난다
- **캐릭터**: 둥근 치비. 큰 머리 + 작은 몸, 굵은 보라 먹선(`#2a1838`), 위에서 오는 빛(위 밝고 아래 어두운 몸통). 직업은 **머리 장식**으로 구분(워든 투구·검사 머리띠·궁수 두건·술사 고깔·기계학자 고글·네크로맨서 후드+빛나는 눈·무투가 붉은 머리띠·초보자 맨머리).
- **몬스터 = 시뮬레이션의 "버그"**: 뭉친 젤리 몸 + 성난 눈, 가장자리에 청록·자홍 **깨진 픽셀**. 종류는 실루엣 장식(뿔·날개·안테나 눈·등가시·균열·포신)으로 구분. 정예·보스는 같은 색 후광.
- **코어**: 새싹이 난 초록 마나 씨앗 결정 + 맥동하는 빛.
- **바닥**: 어두운 흙(`#0e0919`)에 흐린 얼룩·돌조각·마나 이끼, 희미한 옛 격자.
- **이펙트**: 가산 혼합(ADD)으로 빛나게. 색은 데이터의 직업·전직 색을 그대로 쓴다.

## 제작 방식
- 이미지 파일 없이 `prototype/src/art/Art.js`가 캔버스로 그려 텍스처 등록(`hero_<직업>`, `mon_<몬스터>`, `core_seed`, `floor`, `glow`).
- 크기는 데이터 `radius`에 맞춘 배율(`heroScale`, `monScale`) — 충돌 판정은 그대로.
- 움직임: 플레이어 숨쉬기(이동 중 통통), 몬스터 꿈틀거림(개체마다 박자 다름), 피격 흰색/빨강 번쩍임은 틴트.

## 비교안: 도트 (2026-09-29, Lucky 요청)
- 같은 그림을 작은 격자(캐릭터·몬스터 24px, 코어·바닥 32px)로 줄이고(`src/art/pixelize.js`): 가장 가까운 점만 추출 → 반투명 경계 제거 → 색 6단계 → 1px 먹선 외곽. 정예·보스 외곽선은 금색. 작은 눈은 줄이면 사라져 점으로 다시 찍는다.
